
# 🚀 ECOCODE

### Learn. Practice. Create.

ECOCODE is a programming education platform designed to help beginners learn coding through practical lessons and examples.

## 📚 Courses

- HTML
- CSS
- JavaScript
- Python
- C++
- SQL

## 💻 Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## ✨ Features

- Responsive website design
- Searchable programming courses
- Course category filters
- Interactive course information
- Mobile navigation
- Contact form demonstration

## 🌍 Our Mission

To make programming education accessible to everyone through clear explanations and practical learning in English, Russian and Tajik.
