CSS for Beginners

Style web pages with colors, fonts, spacing and layouts.

Welcome to this course

CSS (Cascading Style Sheets) controls how HTML elements look and how a page is arranged.

Work through the lessons in order. Study each example, then practise by changing the code.

Lesson 1: Adding CSS

Read the example and try changing it yourself.

Lesson 2: Colors and text

Read the example and try changing it yourself.

Lesson 3: Spacing and borders

Read the example and try changing it yourself.

Lesson 4: Flexbox layout

Read the example and try changing it yourself.

Lesson 5: Responsive design
