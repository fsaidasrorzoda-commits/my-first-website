SQL for Beginners

Learn to work with information stored in databases.

Welcome to this course

SQL (Structured Query Language) is used to create, read and manage data in relational databases.

Work through the lessons in order. Study each example, then practise by changing the code.

Lesson 1: Create a table

Read the example and try changing it yourself.

CREATE TABLE students (\n  id INTEGER,\n  name TEXT,\n  age INTEGER\n);

Lesson 2: Insert data

Read the example and try changing it yourself.

INSERT INTO students (id, name, age)\nVALUES (1, 'Ali', 15);

Lesson 3: Read data

Read the example and try changing it yourself.

SELECT * FROM students;

Lesson 4: Filter results

Read the example and try changing it yourself.

SELECT name, age\nFROM students\nWHERE age >= 15;

Lesson 5: Sort results

Read the example and try changing it yourself.

SELECT name, age\nFROM students\nORDER BY age DESC;
