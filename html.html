HTML for Beginners

Build the structure of web pages with HTML.

Welcome to this course

HTML is the standard markup language used to structure content on web pages.

Work through the lessons in order. Study each example, then practise by changing the code.

Lesson 1: Your first HTML document

Read the example and try changing it yourself.

<!DOCTYPE html>\n<html>\n<head>\n  <title>My First Page</title>\n</head>\n<body>\n  <h1>Hello, world!</h1>\n  <p>Welcome to my page.</p>\n</body>\n</html>

Lesson 2: Headings and paragraphs

Read the example and try changing it yourself.

<h1>Main heading</h1>\n<h2>Subheading</h2>\n<p>This is a paragraph.</p>

Lesson 3: Links and images

Read the example and try changing it yourself.

<a href="https://example.com">Visit Example</a>\n<img src="photo.jpg" alt="A description">

Lesson 4: Lists

Read the example and try changing it yourself.

<ul>\n  <li>HTML</li>\n  <li>CSS</li>\n  <li>JavaScript</li>\n</ul>

Lesson 5: Forms

Read the example and try changing it yourself.

<form>\n  <label for="name">Your name:</label>\n  <input id="name" type="text">\n  <button type="submit">Send</button>\n</form>
