HTML for Beginners

Start your web development journey. Learn how to create websites using HTML, step by step.

Lesson 1: What is HTML?

HTML stands for HyperText Markup Language.

It is the standard language used to structure content on web pages.

HTML helps us create headings, paragraphs, images, links and more.

Lesson 2: Your First HTML Page

Every basic HTML page has a structure.

<!DOCTYPE html>
<html>
<head>
    <title>My First Website</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>Welcome to ECOCODE!</p>
</body>
</html>

Lesson 3: HTML Headings

HTML has six heading levels, from h1 to h6.

<h1>Main Heading</h1>
<h2>Second Heading</h2>
<h3>Third Heading</h3>

Lesson 4: HTML Paragraphs

Use the p tag to write paragraphs.

<p>I am learning HTML with ECOCODE.</p>

Lesson 5: HTML Links

Use the a tag to create links to other pages.

<a href="https://www.google.com">
    Visit Google
</a>
