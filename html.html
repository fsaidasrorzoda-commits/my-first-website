HTML for Beginners

Build the structure of web pages with HTML.

Welcome to this course

HTML is the standard markup language used to structure content on web pages.

Work through the lessons in order. Study each example, then practise by changing the code.

Lesson 1: Your first HTML document

An HTML document starts with a DOCTYPE declaration and contains HTML, head and body elements. 

<!DOCTYPE html>
<html>
<head>
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>Welcome to my page.</p>
</body>
</html>

Lesson 2: Headings and paragraphs

HTML provides six heading levels, from h1 to h6. Use the paragraph element p for ordinary text. 

<h1>Main heading</h1>
<h2>Subheading</h2>
<p>This is a paragraph.</p>

Lesson 3: Links and images

Use the a element to create links. Use img to display images. The alt attribute describes an image. 

<a href="https://example.com">Visit Example</a>
<img src="photo.jpg" alt="A description">

Lesson 4: Lists

HTML supports ordered lists with ol and unordered lists with ul. Each list item uses li. 

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Lesson 5: Forms

Forms collect information from users. You can use labels, input fields and buttons. 

<form>
  <label for="name">Your name:</label>
  <input id="name" type="text">
  <button type="submit">Send</button>
</form>
